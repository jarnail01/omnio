# 📦 OMNIO
OMNIO is a programmable I/O ASIC for emulating digital protocols such as SPI, I2C, UART, and custom interfaces. It is similar to the PIO state machines on the RP2040.

## 🌟 Highlights
- Entry for [Jane Street Protocol Emulator ASIC Competition](https://blog.janestreet.com/protocol-emulator-asic-competition/)
